# Synthetic evaluation results

Generated by `npm run eval`. These are measured outputs of this implementation, not MediaPipe accuracy or clinical validation. No human images/videos were used.

All cases: 120 s, 30 fps, PRNG seed 42, default detector settings, square image coordinates. Noise is independent uniform ±0.001 x/y unless stated; spikes add 0.12 to both wrist y coordinates every 97 frames. The still case uses noise ±0.003 and spikes every 31 frames. Jitter is uniform ±30% cycle-length variation; reference interval CV is calculated from generated peak timestamps.

Pause durations span the last detected peak to the next (or observation boundary), so they include surrounding partial cycles and differ from the imposed flat-motion duration. CCF is a conservative observed active-time estimate divided by elapsed time, not a clinical CCF measurement. Unknown time is separately disclosed. Arm accuracy counts each visible arm/frame; it is not a participant-based estimate.

Limits: this generator bypasses camera decoding and pose estimation. It does not establish robustness to perspective, occlusion, lighting, real anatomy, camera shake or unrelated periodic movement. Quantized sampling introduces nonzero measured CV even for a perfectly periodic input. This generator does not exercise the browser video adapter; a separate one-off import check in a real browser is recorded in `BROWSER_IMPORT_CHECK.md`. Raw measured values and scenario options are in `results.json`.
